# Нууцлагч (Nuutslagch)

**Хувь хүний мэдээллийг AI-д өгөхөөс өмнө код болгож нуугаад, дараа нь буцааж сэргээдэг үнэгүй, нээлттэй эхийн хэрэгсэл.**

Байгууллагын тайлан, цалингийн хүснэгт, албан бичигт олон зуун хүний нэр, регистр, утасны дугаар байдаг. Ийм баримтыг ChatGPT, Gemini, Claude зэрэг AI-аар засуулах, хураангуйлах үед хувийн мэдээлэл гадагш гарах эрсдэлтэй. Гэвч 500 нэрийг гараар нэг бүрчлэн солих цаг хэнд ч байхгүй.

Нууцлагч энэ ажлыг хоёр товшилтоор хийнэ:

```
Б.Болд (99112233, УБ85010112) Д.Сараа-тай уулзсан
              ↓  🔒 Нууцлах
ХҮН_0001 (УТАС_0001, РД_0001) ХҮН_0002-тай уулзсан      ← үүнийг AI-д өгнө
              ↓  AI засварласны дараа  🔓 Сэргээх
Б.Болд (99112233, УБ85010112) Д.Сараа-тай уулзсан
```

## Онцлог

- **Бүрэн офлайн.** Бүх ажил таны компьютер дээр хийгдэнэ. Программ интернэт рүү юу ч илгээдэггүй.
- **Суулгах шаардлагагүй.** Ганц `.exe` файл. Python болон бусад зүйл хэрэггүй.
- **Монгол хэлэнд зориулсан.** Овгийн 1–3 үсэгтэй нэр (Б.Болд, Ба.Бат-Эрдэнэ), залгавартай нэр (Д.Сараа-тай, Б.Болдод), монгол регистр, утасны дугаарыг таньдаг.
- **Excel, Word, текст.** `.xlsx`, `.docx`, `.txt`, `.csv` файлын өнгө, фонт, хүснэгтийн хэлбэрийг хадгална. Текстийг шууд хуулж буулгаж ч болно.
- **AI-ийн өөрчлөлтийг тэсвэрлэнэ.** AI текстийг дахин бичсэн, мөр, баганыг хольсон, кодыг "хүн 0001", "ХҮН-0001" гэж өөрчилж бичсэн ч зөв сэргээнэ. Код дээр AI залгасан залгаврыг жинхэнэ нэрт нь тааруулж засна (Сараа-гийн, Болд-той).
- **Төрлөөр нь ялгасан код.** `ХҮН_0001`, `РД_0001`, `УТАС_0001`, `ИМЭЙЛ_0001`. AI нэр, дугаарыг хооронд нь андуурахгүй.

## Татаж авах

[**Releases**](../../releases/latest) хэсгээс хамгийн сүүлийн `Nuutslagch.exe`-г татна уу.

> Анх нээхэд Windows **"Windows protected your PC"** гэсэн анхааруулга гаргаж магадгүй. Программ тоон гарын үсэггүй учраас ингэдэг. **More info → Run anyway** гэж дарна. Эргэлзэж байвал доорх зааврын дагуу эх кодоос нь өөрөө бүтээж болно.

## Хэрэглэх заавар

1. `Nuutslagch.exe`-г давхар товшино. Хөтөч дээр программын хуудас нээгдэнэ.
2. **(Заавал биш)** «Нэрсийн жагсаалт нэмэх» товчоор ажилтнуудын нэрсийн Excel эсвэл мөр бүрт нэг нэртэй `.txt` файл ачаална. Ингэвэл "Х." үсэггүй бичигдсэн нэрийг ч олно.
3. Файлаа чирж оруулаад **🔒 Нууцлах** дарна. Хоёр файл татагдана:
   - `..._НУУЦАЛСАН.xlsx`: үүнийг AI-д өгнө
   - `ТҮЛХҮҮР_....json`: **үүнийг өөртөө үлдээнэ. Хэзээ ч AI-д бүү өг!**
4. Программ харуулсан **сануулгыг** файлтайгаа хамт AI-д өгнө. Сануулга нь AI-д кодыг өөрчлөхгүй байхыг заадаг.
5. AI-ийн хариуг (файл эсвэл текст) программд оруулаад **🔓 Сэргээх** дарна. Программ хаагдсан бол эхлээд «Түлхүүр ачаалах» товчоор түлхүүрээ оруулна.

## ⚠️ Хязгаарлалт

- **100% баталгаа өгөхгүй.** "Дамдины Үндрахбаяр", "Төмөрмандах гуай" гэх мэт "Х." үсэггүй бичигдсэн нэрийг зөвхөн нэрсийн жагсаалт ачаалсан үед олно. AI-д өгөхөөсөө өмнө нууцалсан файлыг нэг харж шалгаарай.
- Жагсаалтад "Туяа", "Номин" гэх мэт энгийн үгтэй ижил нэр байвал илүү нууцалж магадгүй. Сэргээхэд буцаад хэвэндээ орох тул алдаа болохгүй.
- Эх баримтад хоёр хүн яг ижил бичигдсэн бол (хоёулаа "Б.Бат-Эрдэнэ") нэг код авна. Овгийг 2 үсгээр бичиж ялгавал (Ба., Бо.) өөр код авна.
- AI тайланг товчлохдоо зарим нэрийг хасаж болно. Энэ нь хэрэгслийн биш, AI-ийн онцлог. **AI-ийн засварласан баримтыг эхтэй нь заавал тулгаж уншина уу.**
- `.xls`, `.doc` хуучин форматыг дэмжихгүй. Office-оор `.xlsx`, `.docx` болгож хадгална уу. Word-д нэр солигдсон догол мөрийн дотоод хэлбэржүүлэлт (хэсэгчилсэн тод, налуу) нэгдэж болно.
- **Төрийн болон албаны нууцтай баримтыг ямар ч AI-д бүү оруул.** Энэ хэрэгсэл хувийн мэдээллийн эрсдэлийг бууруулах зориулалттай, нууцын журмыг орлохгүй.

## Туршилтын файлууд

`examples/` хавтсанд бүрэн **зохиомол** өгөгдөл бий. Бодит хүнтэй холбоогүй:

- `ajiltnuud_500_zohiomol.xlsx`: 500 ажилтны хүснэгт (нэр, регистр, утас, тэмдэглэл)
- `tailan_150_zohiomol.docx`: 150 хүний нэртэй, санаатай дүрмийн алдаатай 5 хуудас тайлан (AI-аар засуулж турших зориулалттай)
- `nersiin_jagsaalt.txt`: тайлангийн нэрсийн жагсаалт

## Эх кодоос бүтээх

[Go](https://go.dev/dl/) 1.22 буюу түүнээс дээш хувилбар хэрэгтэй. Гадны сан ашиглаагүй, зөвхөн Go-гийн стандарт сан.

```bash
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o Nuutslagch.exe .
```

Командын мөрөөр шалгах: `go run . -test examples/ajiltnuud_500_zohiomol.xlsx`

| Файл | Үүрэг |
|---|---|
| `engine.go` | Нэр, регистр, утас, и-мэйл олох, кодлох, сэргээх, залгавар тааруулах |
| `office.go` | Excel, Word файлын дотоод XML-ийг хэлбэржүүлэлтийг нь эвдэлгүй засах |
| `main.go` | Зөвхөн `127.0.0.1` дээр ажилладаг дотоод сервер, хөтөч нээх |
| `ui.html` | Монгол хэлтэй хэрэглэгчийн хуудас |

Шинэ хувилбар гаргахдаа `v1.0.1` гэх мэт шошго push хийхэд GitHub Actions `.exe`-г автоматаар бүтээж Releases-д нийтэлнэ.

### English

**Nuutslagch** is a free, offline Windows tool that replaces personal data in Mongolian documents (names in the `Б.Болд` / `Ба.Бат-Эрдэнэ` style, national registry numbers, phone numbers, emails) with typed codes such as `ХҮН_0001` before you give a document to an AI, and restores the original values afterwards. It handles `.xlsx`, `.docx`, `.txt`, keeps formatting, survives AI rewrites, row/column shuffling and altered code spelling, and fixes Mongolian case endings on restore. Single executable, Go standard library only, nothing leaves your computer. MIT licensed.
